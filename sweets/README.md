# حلويات وآيسكريم البطريق | Penguin Ice Cream & Custom Cakes — صفحة هبوط تسويقية للتطبيق

صفحة هبوط تسويقية متكاملة وخفيفة مصممة لزيادة تحميلات تطبيق الجوال لمحل حلويات وآيسكريم "البطريق"، باللغة العربية مع اتجاه RTL ومطابقة تامة للهوية البصرية لتطبيق الهاتف.

---

## 🎯 الغرض الأساسي من صفحة الهبوط
التطبيق مخصص **للحجز المسبق وتخصيص كيكات المناسبات ومتابعة حالة التجهيز لتجاوز الطوابير والاستلام المباشر من الفروع**. 
لذا تركز صفحة الهبوط على:
1. **تحميل التطبيق أو فتحه فوراً** (أزرار Google Play و App Store والرابط العميق المباشر Deep Link).
2. **استعراض مزايا التطبيق الحصرية** (استوديو تخصيص الكيك، سرعة الحجز المسبق وتجاوز الطوابير، جدولة المناسبات مسبقاً، وإشعارات الجاهزية الفورية).
3. **مجسم هاتف ثلاثي الأبعاد تفاعلي** يعرض الشاشات الحقيقية للتطبيق مع إمكانية التبديل بين شاشة البداية وشاشة الدخول.
4. **الفروع وساعات العمل والخريطة التفاعلية** لسهولة وصول العملاء لاستلام طلباتهم.
5. **قنوات التواصل المباشرة** (واتساب، هاتف، خريطة، وأسئلة شائعة).

## 📁 هيكل المجلد

```
نموذج صفحة هبوط لمحل حلويات/
│
├── index.html                  ← الملف الرئيسي والواجهة
├── README.md                   ← التوثيق ودليل التعديل
│
└── assets/
    ├── css/
    │   └── style.css           ← التصميم الباستيلي الناعم مع السبرنكلز العائمة وإطار الهاتف
    │
    ├── js/
    │   ├── data.js             ← كائن البيانات (معلومات التطبيق، المزايا، خطوات الحجز، المنيو، الفروع، التقييمات)
    │   └── app.js              ← منطق الصفحة (تبديل شاشات الهاتف، فحص الروابط العميقة، الأكورديون، وتنبيه الواتساب)
    │
    └── images/                 ← الأصول البصرية الحقيقية:
        ├── Penguin_ico.png     ← الشعار والأيقونة الرسمية
        ├── Penguin_ar_text.png ← المخطوطة العربية للعلامة
        ├── Penguin_en_text.png ← الاسم الإنجليزي
        ├── App_ico.png         ← أيقونة التطبيق الرسمية
        ├── app-screen-splash.png ← شاشة البداية الحقيقية من التطبيق
        ├── app-screen-login.png  ← شاشة تسجيل الدخول من التطبيق
        └── dessert-1.jpg .. 6  ← صور تشويقية للحلويات والآيسكريم
```
