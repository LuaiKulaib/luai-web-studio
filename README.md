# Portfolio & Landing Pages Showcase
نماذج صفحات هبوط تجارية عصرية مبنية لعرض الأعمال وجذب العملاء.

## 🚀 النماذج المتوفرة:
1. **كروم برو (CHROMEPRO):** صفحة هبوط لمركز حماية وتظليل وزينة سيارات فاخرة (Dark Automotive UI + حاسبة تفاعلية + مقارنة قبل وبعد).
2. **حلويات البطريق (Penguin Sweets):** صفحة هبوط لمحل حلويات وآيسكريم وتطبيق طلب مسبق (موك أب جوال تفاعلي + استعراض المنيو + فروع).
3. **دار الأواني للتجارة والجملة (Dar Al-Awani Wholesale):** صفحة هبوط B2B لتوريد الأدوات المنزلية وأواني الضيافة بالجملة (كتالوج كراتين وشرائح تفاعلي + سلة تسعيرة جملة للواتساب + حاسبة أرباح التاجر).

## 🛠️ التقنيات المستخدمة:
- HTML5 / CSS3 (Modern Responsive Flexbox & Grid)
- Pure JavaScript (ES6+)
- Zero external heavy dependencies (فائقة السرعة والتحميل)
